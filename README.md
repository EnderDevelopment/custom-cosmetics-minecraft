# EnderDev Cosmetics

EnderDev Cosmetics is a Minecraft mod that allows players to create, manage, and equip custom cosmetics like hats, wings, and capes. This mod provides a clear, easy-to-use in-game menu where players can browse their cosmetics, equip them, and remove them. The menu includes a preview of the player's character so they can see how a cosmetic looks before equipping it. Players can wear multiple cosmetics at the same time as long as they occupy different slots. Equipped cosmetics are saved for the player's account and automatically restored the next time they launch the game. All cosmetics are purely visual and provide no gameplay advantages.

## Install

1. Download the mod from the [GitHub releases page](https://github.com/EnderDevelopment/enderdev-cosmetics/releases).
2. Place the downloaded `.jar` file into the `mods` folder of your Minecraft instance.
3. Launch Minecraft with the Fabric loader installed.

## Use

1. Launch Minecraft and load a world.
2. Press the `C` key to open the cosmetics menu.
3. Browse the available cosmetics and click on a cosmetic to preview it.
4. Click the equip button to equip the cosmetic.
5. Equipped cosmetics will be saved and automatically restored the next time you launch the game.
